# 🌸 Mittsunee Commission Web

Official Commission & Portfolio website for **Mittsunee** — Illustrator, Character Designer, and Live2D Artist.

A modern, responsive, and aesthetic web application built with React, Vite, Tailwind CSS, Lucide icons, and Supabase integration.

---

## ✨ Features

- **🌸 Interactive Landing & Commission Page**:
  - Hero banner with mascot animations and quick commission status.
  - Commission types (Chibi, Skeb, Headshot/Bust-up, Half Body, Full Body, Character Sheet, Live2D Model).
  - Terms of Service (TOS), workflow guide, and FAQ.
- **🎨 Dynamic Portfolio Gallery**:
  - Connected with **Supabase Database & Storage**.
  - Mascot loading animation on initial data fetch.
  - Fixed aspect ratio grid layout with shimmer skeleton animation while images are loading.
  - Infinite scroll pagination for seamless browsing experience.
  - Filter by category (Illustration, Chibi, Skeb, Live2D).
  - Fullscreen Lightbox viewer with zoom & pan preview.
- **🔐 Secret Admin Panel **:
  - Direct portfolio management (upload new artworks, edit titles/categories, delete artworks).
  - WebP conversion support and Supabase Storage integration.
- **🎵 BGM Player & Interactive Sound FX**:
  - Background music player with volume control and ambient sound effects.
- **📱 Fully Responsive**:
  - Optimized for mobile, tablet, and desktop devices.

---

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/), [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/), Custom Design Tokens & Shimmer Animations
- **Icons & Motion**: [Lucide React](https://lucide.dev/), [Framer Motion](https://www.framer.com/motion/)
- **Backend & Storage**: [Supabase](https://supabase.com/) (PostgreSQL & Object Storage)
- **Image Optimization**: WebP format with high quality preservation
